# Support

- For reproducible bugs, documentation problems, and feature requests, use
  [GitHub Issues](https://github.com/takuphilchan/offgrid-llm/issues). Include
  the OffGrid version, platform, expected behavior, actual behavior, and safe
  reproduction steps. Remove credentials, private prompts, logs containing
  personal information, and model files before posting.
- For setup and troubleshooting, first check the [documentation index](docs/README.md)
  and [installation guide](docs/setup/installation.md). General contributor
  discussion can use the community link maintained in the [root README](README.md#community).
  Reproducible defects still belong in GitHub Issues so they remain trackable.
- For vulnerabilities or sensitive security details, do not use a public issue
  or Discord. Follow [Security](SECURITY.md) for private reporting and the
  fallback when GitHub's private-report button is unavailable.

Community help is best-effort, not an operational support SLA.
