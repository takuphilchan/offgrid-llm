# Security policy

Please do not disclose a suspected vulnerability, exploit steps, credentials,
private data, or a proof of concept in a public issue, discussion, or Discord
message.

Use the repository's [Security Advisories](https://github.com/takuphilchan/offgrid-llm/security/advisories)
page and select **Report a vulnerability** if GitHub presents that option. It
opens a private report to the maintainers. Include the affected version,
reproduction steps, impact, and a way to contact you; avoid attaching real user
data or secrets. GitHub private vulnerability reporting must be enabled in the
repository settings for that option to appear.

If that option is unavailable, open a minimal [issue](https://github.com/takuphilchan/offgrid-llm/issues/new)
asking the maintainers to provide a private reporting channel. Do **not** put
the vulnerability details in that issue. The availability of private reporting
has not been independently confirmed for this repository.

The maintainers will acknowledge a private report, assess it, and coordinate
remediation and disclosure through the private channel. No response-time or
support guarantee is promised here. For ordinary bugs and usage questions, use
[Support](SUPPORT.md) instead.
