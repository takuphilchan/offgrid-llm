# Runtime composition baseline (2026-10-21)

The current `internal/server/construction_legacy.go` is the sole broad production constructor. `NewWithConfig` validates config, acquires storage ownership, prepares the data layout, obtains workspace identity, then constructs registry/engine/resource monitor/stats/cache/embedding, scans models, starts the monitor, rate limiters, RAG, sessions and provider scheduler. It then creates user/quota/knowledge/LoRA state, a lazy sandbox and agent/tool capability stack, run/artifact stores, integrations/metrics/WebSocket, power/degradation/audit/auth/LDAP/MCP/load-balancing/distributed RAG/plugins/P2P, detects resources, creates the model cache, and finally assembles `Server`. After assembly it wires process retirement, download recovery, session callbacks, browser hub, agent runner/coordinator and conversation recovery.

Early failures of validation, ownership, data layout, workspace ID, turn recovery or scheduler creation return a partially initialized `Server` with `startupErr`; ownership is explicitly closed on several of those branches. Later retirement, download and conversation-recovery failures record `startupErr` on a fully or partly running server. In particular, cache/monitor/power/degradation/WebSocket work can start before some error branches, so ownership release alone is not proof of complete cleanup. This is the risk Phase 7 must eliminate, not a claim that current behavior is safe to alter without tests.

`Server.Start` seals native installation, checks `startupErr` and listener exposure, builds the frozen router, configures one `http.Server`, starts shutdown/RAG/metrics/P2P helpers, binds once and serves. `Server.Close` drains HTTP, agent workers and model checks before resource cleanup; on an uncertain drain it retains workspace ownership. The root CLI production adapter in `cmd/offgrid/legacy_server_start.go` calls `server.NewWithConfig(cfg).Start()`. Direct constructor uses also exist in `cmd/offgrid/legacy_server_start_test.go`, `internal/server/server_test.go` and `internal/server/ownership_test.go`; many other tests call their shared disposable fixture.

The Phase 6 route fixture passed on this baseline (`go test ./internal/server -run '^TestServerRouteRegistrationContract$' -count=1`), covering 136 registrations and four outer wrappers. `rg -n 'NewWithConfig|startupErr|\.Close\(' internal/server cmd/offgrid` supplied the caller/error inventory. No installed service, user workspace or native desktop was touched.
