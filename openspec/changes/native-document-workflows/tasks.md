# Tasks

Implementation is in progress. Read proposal.md, design.md and all three spec
deltas before applying. Existing uncertain tasks and personal application state
must remain untouched. A checked task requires its implementation, regression
tests and stated documentation to be complete, with actual check results recorded.

Commands below run from the repository root. Use `npm.cmd` on Windows and `npm`
on Linux/macOS. Race tests require a supported Go/CGO environment. Native-input
checks require an explicitly isolated desktop/account and fixture-only targets;
ordinary unit commands must not enable them. New harness commands are identified
as deliverables, not existing scripts. Missing platform evidence leaves the
corresponding task incomplete.
