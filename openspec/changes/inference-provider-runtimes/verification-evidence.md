## MLX cancellation boundary (2026-10-21)

- The worker now explicitly closes an MLX generation iterator before releasing
  the active request. If stream cleanup fails, it marks the worker unhealthy
  and emits an operational error instead of a terminal success; the supervisor
  must replace it before another generation. Fixture tests cover cancellation
  and failed cleanup. The Python SDK/worker suite passed 74 tests, and the
  focused Go inference suite passed. This is source/protocol evidence only,
  not an Apple Silicon Metal run or task 3.1 qualification.
