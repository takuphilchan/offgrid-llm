# Code of conduct

OffGrid's project spaces are for constructive collaboration. Participants are
expected to be respectful, assume good faith, and discuss technical choices
without personal attacks. Harassment, threats, discriminatory language,
unwanted sexual attention, doxxing, and publishing another person's private
information are not acceptable.

This applies to repository issues, pull requests, reviews, and project-run
community spaces. Maintainers may edit, hide, or remove harmful content and
restrict participation when needed. They will consider context and impact,
and will avoid disclosing a reporter's identity unnecessarily.

For a conduct concern, request a private contact channel from the maintainers
without posting sensitive details publicly. If the concern also involves a
software vulnerability, follow the [security policy](SECURITY.md). This
document does not imply that an unofficial Discord server or an unverified
private inbox is monitored by the project.
