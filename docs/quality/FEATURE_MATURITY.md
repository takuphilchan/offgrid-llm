# Feature maturity

The [engineering audit ownership map](ENGINEERING_AUDIT.md#ownership-and-evidence-map) is the maintained feature matrix. The [dated browser evidence](evidence/browser-execution-2026-11-20.md) records this increment's actual checks. Existing dated evidence remains authoritative for previous increments.

Use separate states: implemented source, automated contracts tested, real model/profile tested, installed edition tested, and qualified for release. None implies the next. Partially implemented, experimental and absent capabilities remain explicit in the map and [roadmap](../ROADMAP.md).
