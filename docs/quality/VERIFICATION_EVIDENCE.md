New evidence must include source identity/worktree scope, environment and pinned
runtime/model versions, fixture ownership, commands, actual outcomes, failed
attempts, skipped/unrun cases and limitations. Qualification records also need
frozen cases, repeat counts, raw outcome/latency/resource measurements and the
independent oracle or human judgement used. A model judging its own narrative
is not independent artifact verification.

After implementation changes, re-run affected checks before carrying forward
older passes. Complete applicable CI for integration readiness, then separately
qualify the real hardware, packaged editions, corpus, soak and user gates in the
[production-readiness contract](production-readiness.md). Publication and live
installation replacement remain separate authorization decisions.
