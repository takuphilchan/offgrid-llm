## Test record

Initial web type check passed. Initial desktop suite: 234 passed, one skipped. The first full Go run failed in `internal/server`; it is not a clean baseline. A later focused run exposed the new discovery tool leaking into the legacy nine-tool compatibility probe; the tool now requires negotiated discovery, and the affected probe tests pass. Full final results are recorded in [browser execution evidence](evidence/browser-execution-2026-11-20.md), including checks still unavailable. Failed intermediate runs are not erased by subsequent successful runs.

No installed application, personal browser profile, user document or model weight was changed by these browser fixtures. They use disposable local HTTP pages and headless Chromium. No commit, publication, installed native-control exercise or release qualification is implied.
