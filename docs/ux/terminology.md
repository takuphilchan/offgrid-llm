# Workspace terminology

| Term | Meaning and usage |
| --- | --- |
| Chat | Write requests and read answers; start agent work here |
| Agent profile | Reusable instructions, model and permitted resources; configuring it does not run work |
| Task | One saved unit of agent work with its own state, result and evidence |
| Activity | Inspect tasks, their results and available execution details |
| Model | Installed model data used by a compatible local runtime; installation alone does not prove readiness |
| Language model | Produces text for conversations and supported agent workflows |
| Embedding model | Makes document search possible; it does not answer chat messages |
| Knowledge | Documents available to supported retrieval; adding a document does not mean it is indexed or used |
| Indexed | Document processing completed for search; an answer must still cite/use actual retrieved evidence |
| Connection | An attached service/tool source, not a grant to execute it |
| Workspace access | Scoped file/process access; distinct from desktop computer control |
| Approval | Exact pending operation, bound to actor and expiry; not reusable blanket authority |
| Service unavailable | OffGrid cannot reach its configured service; does not prove internet failure |
| Offline | Internet unavailable; local capabilities depend on the local service and installed runtimes |
| Completed | Recorded task state; verification/effect uncertainty remains separately visible |

Button labels retain their existing translated action terms. New explanatory
copy is typed under `Messages.guidance`; no opaque technical identifier is renamed.
English is reviewed for the current scope. French, Spanish, German, Arabic,
Kiswahili, ChiShona, isiNdebele and isiZulu additions require native-speaker review
before claiming linguistic qualification. The keys needing review are listed in
the final evidence report; type checking establishes completeness only.
