# Target architecture

Extend the [current service boundaries](CURRENT_STATE.md), retaining one authoritative workspace and executor. The [roadmap milestones](../ROADMAP.md#approved-transformation-program-2026-11-20) own sequence and acceptance.

- A canonical work record connects conversation, jobs, inputs, artifacts and source evidence across clients; durable controls support steering, pause, background and Stop.
- A shared browser contract separates managed and selected signed-in-tab adapters. Session/tab/frame/document identities, observed references and structured effect receipts remain explicit. Network and attachment scope are authorized resources, not guessed from page text.
- Providers report text/tool/vision/voice/image capability and resource demand separately. Existing scheduling admits explicit model pools; no silent remote fallback. Image jobs and compatibility transports reuse the same application services.
- Knowledge and memory preserve ownership, source revision, provenance and revocation. Deterministic workflows reuse durable jobs and verification.
- Later enrolled nodes receive scoped work under leases and fencing. Artifact transfers preserve integrity and access; uncertainty prevents duplicate external effects. Distribution does not create new authority.

Compatibility, privacy, backup/restore and independently measured quality are constraints on every increment. The current implementation and outstanding gaps are recorded in the [audit](../quality/ENGINEERING_AUDIT.md).
