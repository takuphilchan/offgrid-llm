# Contributing

Start with the root [contribution guide](../../CONTRIBUTING.md), [repository map](../repository-structure.md), and [OpenSpec workflow](../../openspec/README.md). [Code style](code-style.md) and [maintainability](../advanced/maintainability.md) cover implementation review.

Current product requirements live in `openspec/specs/`. Active changes are proposed or in progress; checked tasks alone are not proof of independent testing or release qualification. See [quality](../quality/README.md) for evidence and [the roadmap](../ROADMAP.md) for planned work.
