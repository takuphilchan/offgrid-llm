# Private AI operating platform

OffGrid should offer dependable local models, conversational agents, knowledge and workflows through one coherent product, with explicit control of data and execution. A useful single computer comes first; distributed tasks follow proven local reliability.

Keep Go application services, the shared React interface, Electron, CLI and SDK. Improve task completion, usability, recovery and evidence rather than adding a second executor or cloning another product's interface. macOS polish, Apple Silicon performance, voice, vision, image generation and developer compatibility remain first-class requirements alongside Windows/Linux and self-hosted deployment.

The [single roadmap](../ROADMAP.md) records the complete approved implementation program. The [maturity map](../quality/FEATURE_MATURITY.md) distinguishes source capability from tested quality. [Production readiness](../quality/production-readiness.md) controls qualification, not ambitions or popularity comparisons.
